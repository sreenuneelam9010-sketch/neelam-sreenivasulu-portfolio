## Featured Projects

### 1. Sri Venkateswara Lakshmi Venkateswara Farm Management System
*Real-world full-stack farm and livestock management application (~90% developed by Neelam Sreenivasulu).*
- **Tech Stack**: HTML5, CSS3, JavaScript, Python, MySQL, Git, GitHub
- **Highlights**: Role-based access control (Owner/Worker/Customer), real-time livestock health tracking, feed inventory replenishment alerts, customer order lifecycle, and normalized MySQL relational schema.

### 2. Hospital Management System for Secure Healthcare
*Secure health record management system with cryptographic patient data protection.*
- **Tech Stack**: Python, Flask, MySQL, HTML, CSS, JavaScript, Bootstrap, AES-256, SHA-1
- **Highlights**: Role-based access control for Doctors, Receptionists, and Admins, encrypted Electronic Health Records (EHR), and audit logs.

### 3. Customer Churn Prediction System
*End-to-end Machine Learning classification model to identify telecom customer attrition risk.*
- **Tech Stack**: Python, Pandas, NumPy, Scikit-Learn, Random Forest, SVC, Matplotlib, Seaborn
- **Highlights**: Exploratory Data Analysis (EDA), feature engineering on customer tenure & contract types, and high classification accuracy (94.8%).

### 4. Ticket Booking Web Application
*Enterprise-ready movie ticket booking platform with atomic seat allocation.*
- **Tech Stack**: Java, HTML, CSS, JavaScript, MySQL, JDBC, Servlets
- **Highlights**: Real-time interactive seat grid, ACID transaction isolation, and secure session management.

## Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/sreenuneelam9010-sketch/neelam-sreenivasulu-portfolio.git

# Navigate into project directory
cd neelam-sreenivasulu-portfolio

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
```
